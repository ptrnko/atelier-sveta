ART SCHOOL — PROJECT DOCUMENTATION

Папка містить стартову структуру документації для проєкту Atelier Sveta.

Основні документи:
01_Strategy — бізнес-цілі, персони, сценарії, позиціонування і Tone of Voice.
02_Product — PRD, sitemap та контент-модель.
03_Admin — документація адмін-панелі (наступний етап).
04_Content — тексти, локалізація, translation matrix.
05_Research — конкуренти, інтерв’ю, референси.
06_Design — wireframes, UI concepts, design system.
07_Delivery — analytics plan, QA checklist, decision log.
