# Atelier Sveta Site

This folder contains the public website starter for Atelier Sveta.

## Local Preview

Open `index.html` in a browser, or run a small local server from this folder:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Structure

- `index.html` — first working page.
- `assets/styles.css` — visual style and responsive layout.
- `assets/main.js` — light client-side behavior.
- `content/site-content.js` — structured project constants for the future CMS or frontend.
